# IVVISION
Computer Vision model for Dance Group Analysis and Exportation.

First, download main.py and ui.py. 

Downloading draw.py is completely optional. 

If you download main.py, make sure to adjust the video_path value at the top of the file. Then, run the code with main.py. 

Once that is complete, feed the raw video and the new boxes into the ui.py file, click on the person you want tracked, then hit export.
